Pengaturan Aplikasi

Jalankan Otomatis (Autostart)

Aktifkan opsi ini agar server WhatsApp Blast otomatis berjalan di latar belakang setiap kali komputer Anda dinyalakan.

Mode Fokus Gen-Z (Dimming)

Meredupkan balon chat wawancara dan kartu follow-up pasif untuk mereduksi distraksi visual serta meningkatkan fokus membaca.

💡 Informasi Cara Kerja:
Fitur ini membuat shortcut ke launcher Launcher.exe di folder startup Windows (shell:startup) agar server dan dashboard terbuka otomatis saat booting.

Data Uji Coba (Database Sandbox)

Populasikan database dengan data dummy profesional (riwayat rekap campaign, grafik performa, dan pesan masuk pelanggan) untuk menguji seluruh fitur dashboard secara instan.

Informasi Versi & Auto-Update Aplikasi

Sistem pembaruan otomatis (Auto-Updater) terintegrasi secara langsung dengan server GitHub Releases untuk menjamin Anda selalu mendapatkan fitur dan keamanan terbaru.
